## BLE протокол

![BLE struct | 1000](primastem_ble_robot.jpg)

Робот принимает специальный пакет данных, представляющий из себя команду. Когда робот начнет ее исполнять то вернет состояние `busy`. Когда команда будет исполнена, робот вернет `free` и тогда можно будет посылать следующую.

Робот содержит единственный BLE сервис (`0x0100`) в котором есть 2 характеристики:

1) `0x0101` - Характеристика для передачи команд. Поддерживает чтение и запись.
2) `0x0102` - Характеристика состояния. Поддерживает подписку. Данная характеристика возвращает байт `0x00` - free когда робот закончил исполнение команды и свободен и байт `0x01` - busy когда робот начал исполнять команду.

Управляющие команды состоят из 9 байт и описываются структурой`cmd`, состоящей из:

- `type` - это тип команды описываемый `enum`.
- `main` - это основной параметр команды.
- `second` - вспомогательный параметр команды.

Возможные команды:

| Команда     | Байт   | Блокирующая |
| ----------- | ------ | ----------- |
| `cmd_log`   | `0x01` | Нет         |
| `cmd_move`  | `0x02` | Да          |
| `cmd_led`   | `0x03` | Да          |
| `cmd_sound` | `0x03` | Нет         |
| `cmd_conf`  | `0x04` | Да          |
| `cmd_name`  | `0xAA` | Reset       |
| `cmd_break` | `0xFF` | Нет         |

- `cmd_log` - Данная команда печатает лог, параметров нет.
- `cmd_break` - Команда прерывает исполнение текущей команды.
- `cmd_name` - Команда устанавливает имя и перезагружает робота.
	- `main` -  4 случайных символа которые будут добавлены к имени.
- `cmd_move` - Команда перемещения.
	- `main` - направление перемещения (`uint8_t` в правом байте)
		- `'f'` - вперед
		- `'b'` - назад
		- `'r'` - вправо (поворот по часовой)
		- `'l'` - влево (поворот против часовой)
	- `second` - "размер" движения:
		- Для вращения - угол в градусах.
		- Для перемещения расстояние в мм.
- `cmd_led` - команда для вкл/выкл светодиодов робота.
	- `main` - Положение диода (`uint8_t` в правом байте)
		- `'l'` - левый диод
		- `'r'` - правый диод
		- `'b'` - оба диода
	- `second` - цвет  (`uint8_t` в правом байте)
		- `'r'` - красный
		- `'g'` - зеленый
		- `'b'` - голубой
		- `'w'` - белый
- `cmd_sound` - Команда запускает аудио файл.
	- `main`  - ожидает название аудио файла который нужно воспроизвести.(ожидается что аудио файлы имеют названия формата `XXX.mp3`)
- `cmd_conf` - Команда запускает процесс настройки робота.
	- `main`  - Конкретная команда настройки (`uint8_t` в правом байте)
		- `'l'` - Калибровка длинны.
		- `'i'` - Калибровка инерционного сенсора.
	- `second` - Параметр настройки:
		- Для калибровки длинны - длинна линии нарисованной роботом с дефолтной длинной (150 мм).
		- Для инерционного сенсора - пустое.

Пример комманды движения Вперед на 90мм:

| type       | main       | second     |
| ---------- | ---------- | ---------- |
| `cmd_move` | forward    | 90 mm      |
| 0x02       | 'f'        | 90         |
| 0x02       | 0x00000066 | 0x0000005A |

В итоге нужно послать (например через NRFconnect)`0x02 0x66 0x00 0x00 0x00 0x5A 0x00 0x00 0x00`.

Команды которые не отмечены как блокирующие не будут приводить к отправке статуса. Команда которая помечена как `Reset` приведет к перезапуску робота.

Робот до первого подключения будет иметь имя `ROBOTAAAA`, к нему можно подключится и изменить 4 последних символа с помощью команды `cmd_name`. Робот сохранит эти символы и дальше по ним можно будет находить данного робота. Напримет можно передать [0xAA, 'ABCD', 0x00000000] и это задаст имя `ROBOTABCD`. Несмотря та то что уже установлено имя отличное от `ROBOTAAAA` его можно поменять в любой момент.
