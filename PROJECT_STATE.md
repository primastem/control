## Протокол (кратко) — полный текст в docs/ble-protocol.*.md
- Сервис `0x0100`, характеристики: `0x0101` команды (R/W), `0x0102` статус (notify: 0x00 free / 0x01 busy).
- **Реальные UUID (кастомная база, подтверждено макросом прошивки UUID_CREATE):**
  формула `bd9e1632-<a:04x>-4d63-ad5f-27f115379843`
  - сервис  = `bd9e1632-0100-4d63-ad5f-27f115379843`
  - команда = `bd9e1632-0101-4d63-ad5f-27f115379843`
  - статус  = `bd9e1632-0102-4d63-ad5f-27f115379843`
  Короткие 0x01xx — только ярлыки, для подключения НЕ годятся.
- Пакет команды: 9 байт = `type`(uint8) + `main`(uint32) + `second`(uint32), **little-endian**.
- Команды (enum `ble_cmd_type_t`): log=0x01, move=0x02, led=0x03, sound=0x04, conf=0x05, lvl=0x06(не описана), name=0xAA, break=0xFF.
- move: main = направление 'f'/'b'/'r'/'l' (код символа в правом байте), second = мм (перемещение) или градусы (поворот).
- led: main = 'l'/'r'/'b' (диод), second = 'r'/'g'/'b'/'w' (цвет). Блокирующая.
- sound: main = имя аудиофайла (формат XXX.mp3). Неблокирующая.
- conf: main = 'l' (калибровка длины) / 'i' (калибровка IMU), second = параметр.
- break(0xFF): СТОП, прерывает текущую команду.
- name(0xAA): main = 4 символа → имя ROBOTxxxx, робот перезагружается.
- Пример: вперёд 90 мм = `02 66 00 00 00 5A 00 00 00`.
- Робот: имя ROBOTZCTN, MAC 50:78:7D:0B:0A:3A (тестовый экземпляр).

## Реализовано сейчас
- Подключение (filter namePrefix "ROBOT", optionalServices = service UUID).
- Движение: вперёд/назад/влево/вправо + СТОП (cmd_break).
- Поля «Дистанция» (дефолт 150 мм, для вперёд/назад) и «Угол» (дефолт 90°, для поворотов) — редактируемые.
- Подписка на статус 0x0102: индикатор free/busy, блокировка кнопок пока busy.
- Языки EN (по умолчанию) / FR / RU, переключатель, выбор в localStorage (ключ `ps_lang`).
- Раздел «Настройки BLE»: 3 поля UUID (заполнены реальными значениями, редактируемые).
- Фирменная тёмная палитра docs.primastem.com: зелёный #68B833/#5AA02C/#4D8825, фон #121512, карточки #1c1f1a/#2a2d27, границы white@10%, текст белый, muted #A1A39F. Текст на зелёных кнопках — белый (--on-accent:#fff).
- Проверка совместимости: предупреждение если нет Web Bluetooth или открыто из file:// (нужен https/localhost).

## План работ (приоритет — СЕЙЧАС, минимальный набор; согласовано с командой)
1. **LED (cmd_led 0x03):** блок выбора диода (л/п/оба) + 4 цвета (кр/зел/голуб/бел). Неблок? — нет, блокирующая, ждём free.
2. **Звук (cmd_sound 0x04):** список имён файлов из Audio Files Reference (https://docs.primastem.com → /en/sounds_reference) ИЛИ поле ввода. ЗАВИСИМОСТЬ: подтвердить список файлов. Неблокирующая — не ждать статус.
3. **Клавиши-стрелки:** ↑↓←→ = движение, пробел = СТОП. Только когда фокус не в input.
4. **Пресеты дистанции/угла:** быстрые кнопки 50/100/150 мм и 45/90/180°.
5. **Запоминание + переподключение:** хранить последние дистанцию/угол/язык/имя робота в localStorage; кнопка «Подключиться к последнему» (полный автоконнект в Web Bluetooth невозможен без жеста пользователя).
6. **Сырой hex-отправитель:** поля type/main/second или 9 байт hex → запись в характеристику. Для теста cmd_lvl 0x06 и будущих команд.
7. **Watchdog:** если после блокирующей команды статус не вернул free за N секунд — разблокировать кнопки + предупреждение в логе.

## Будущие «хотелки» (НЕ сейчас, по решению команды)
- **Конструктор программ:** цепочка команд + «Запуск» с ожиданием free между блокирующими. Сильно в духе продукта, но продукт «без экрана» — позиционировать как демо/инструмент, не замену токенам.
- **Распространение:** разместить онлайн по https (поддомен типа control.primastem.com или GitHub Pages) — без этого не запустить с телефона; iOS Safari не поддерживает Web Bluetooth (обход: браузер Bluefy или нативная обёртка Capacitor).
- **PWA:** manifest + service worker, установка «на экран», офлайн.
- **Калибровка (cmd_conf 0x05)** и **переименование робота (cmd_name 0xAA)** — отложены.

## Открытые вопросы
- `cmd_lvl` (0x06): назначение/параметры неизвестны — проверить «сырым» отправителем (п.6) опытным путём, затем дописать в docs.
- Список аудиофайлов для звука — взять/подтвердить (нужно для п.2).

## Как запускать (важно)
Web Bluetooth НЕ работает из file://. Нужен https или localhost:
```
cd C:\Users\andrei\Documents\Claude\Projects\BLE
python -m http.server 8000
# открыть http://localhost:8000/primastem-robot-control.html в Chrome/Edge
```
На телефоне (Android) — разместить по https. iOS — только через браузер Bluefy.

## Заметки по реализации
- Сборка пакета: `DataView`, setUint8(0,type), setUint32(1,main,true), setUint32(5,second,true) — LE, проверено против примера протокола.
- Запись: `writeValueWithResponse` (характеристика R/W), fallback `writeValue`.
- i18n: словарь I18N {en,fr,ru}, элементы помечены `data-i18n`, setLang() обновляет тексты + классы кнопок.
- Все цвета — через CSS-переменные в :root, легко менять.
